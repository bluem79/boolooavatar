Boolooavatar Web (v3)

A simple web avatar for streaming. Upload up to 5 images or videos for each state (idle, talking, playing, screaming) and they play at random. Talking and screaming are detected from your microphone. You can also trigger emoji reactions and full-avatar reaction clips, and control them from your phone.

Files

  • boolooavatar-v3.html: the main avatar page.
  • remote.html: the phone remote control page.

Step 1: Put the files on GitHub (one time)

  1. Create a free account at github.com.
  2. Click New repository. Name it boolooavatar, set it to Public, and click Create repository.
  3. Click uploading an existing file and upload both files. Do not rename them.
  4. Click Commit changes.
  5. Go to Settings → Pages. Under Branch choose main and click Save.
  6. Wait 1–2 minutes. Your addresses will be (replace YOURNAME with your GitHub username):
    • Main page: https://YOURNAME.github.io/boolooavatar/boolooavatar-v3.html
    • Remote: https://YOURNAME.github.io/boolooavatar/remote.html

Step 2: Set up the main page (on your computer)

  1. Open the main page in Chrome.
  2. Upload your avatar files into each state. Click Turn on microphone and allow access.
  3. Adjust the two sliders (talking and screaming thresholds) while you speak, until the states switch the way you like.
  4. Optional: pick a background color, or upload a background image.
  5. In the Remote control box, type a long, unique room code (for example boolooavatar-x7k29qpm41) and click Connect. You should see Connected ✓.

Step 3: Use the remote (on your phone)

  1. Open the remote address in your phone browser.
  2. Type the same room code and tap Save.
  3. Tap the buttons. Emoji buttons trigger emoji reactions. The 🎬 buttons play full-avatar clips. The 🎮 button toggles playing mode.
  4. Open Edit labels to rename the emoji and clip buttons.

Step 4: Use it in OBS

  1. Keep the main page open in Chrome and press H to show only the avatar (press H or double-click to go back).
  2. In OBS add a Window Capture source and select the Chrome window.
  3. Right-click the source, choose Filters, and add Chroma Key (use green if your background is green).

Alternative: use a Browser Source with the address https://YOURNAME.github.io/boolooavatar/boolooavatar-v3.html?room=YOURCODE#clean. OBS stores files separately from Chrome, so upload your avatar files again inside OBS (right-click the source → Interact). Click once on the avatar in Interact to enable the microphone.

Reactions

  • Emoji reactions (keys 1–5): floating emoji or a small custom image, with an optional sound. Edit them in the custom reactions box.
  • Clip reactions (keys Q W E R T): up to 5 images or videos per reaction that replace the avatar for a moment, then return. Use the same size and background as your avatar files. The video's own audio is muted.

Keyboard shortcuts

  • P playing mode · H avatar-only mode · 1–5 emoji reactions · Q W E R T clip reactions

Option B: Local mode (no limits, no internet relay)

Windows without Python: put server.ps1 and start-windows.bat in the same folder as the other files, then double-click start-windows.bat and accept the administrator prompt. Nothing needs to be installed. Use it instead of steps 2 and 3 below. If Windows shows a blue SmartScreen warning, choose More info → Run anyway.

If you want a remote with no third-party limits at all, run the small local server on your PC. Your phone and PC must be on the same Wi-Fi.

  1. Put server.py, boolooavatar-v3.html and remote.html in one folder on your PC.
  2. Install Python from python.org if you do not have it (on Windows tick Add Python to PATH).
  3. Open a terminal in that folder and run python server.py. Keep the window open. Allow it through the firewall if Windows asks (private networks).
  4. The window prints your addresses. On the PC open http://localhost:8765/. In OBS use http://localhost:8765/#clean. On your phone open http://YOUR-PC-IP:8765/remote (the exact address is printed).
  5. No room code is needed in this mode. The status text says Connected (local). Upload your avatar files again once, because this address has its own storage.

Good to know

  • The room code and the Remote only work when the files are hosted by you (GitHub Pages) or opened locally. They do not work inside pages hosted on claude.ai.
  • The remote uses the free public MQTT brokers (EMQX and HiveMQ). The room code is the only secret, so use a long code that nobody can guess.
  • Your files are saved in the browser on that device. Another browser or device starts empty.
  • Remote control and OBS features were not tested by the author. If something fails, check that the room code is identical in both places.

Boolooavatar Web (نسخه v3)

یه اواتار ساده تحت وب برای استریم. برای هر حالت (بیکار، حرف زدن، بازی، جیغ) تا ۵ تصویر یا ویدیو آپلود می‌کنید و به‌صورت رندوم پخش می‌شن. حالت حرف زدن و جیغ با میکروفون تشخیص داده می‌شه. ریکشن‌های ایموجی و کلیپ‌های تمام‌اواتار هم دارید و می‌تونید از گوشی کنترلشون کنید.

فایل‌ها

  • boolooavatar-v3.html: صفحه اصلی اواتار.
  • remote.html: صفحه ریموت برای گوشی.

قدم ۱: گذاشتن فایل‌ها روی GitHub (فقط یه بار)

  1. توی github.com یه اکانت رایگان بسازید.
  2. روی New repository بزنید. اسمش رو boolooavatar بذارید، روی Public بذارید و Create repository رو بزنید.
  3. روی uploading an existing file بزنید و هر دو فایل رو آپلود کنید. اسم فایل‌ها رو عوض نکنید.
  4. روی Commit changes بزنید.
  5. به Settings ← Pages برید. زیر Branch، گزینه main رو انتخاب کنید و Save بزنید.
  6. یکی دو دقیقه صبر کنید. آدرس‌ها این‌طور می‌شن (به‌جای YOURNAME اسم کاربری گیت‌هابتون رو بذارید):
    • صفحه اصلی: https://YOURNAME.github.io/boolooavatar/boolooavatar-v3.html
    • ریموت: https://YOURNAME.github.io/boolooavatar/remote.html

قدم ۲: تنظیم صفحه اصلی (روی کامپیوتر)

  1. صفحه اصلی رو توی کروم باز کنید.
  2. فایل‌های اواتار رو توی هر حالت آپلود کنید. دکمه روشن کردن میکروفون رو بزنید و اجازه بدید.
  3. وقتی حرف می‌زنید، دو اسلایدر آستانه (حرف زدن و جیغ) رو تنظیم کنید تا حالت‌ها همون‌طور که می‌خواید عوض بشن.
  4. اختیاری: رنگ پس‌زمینه رو انتخاب کنید یا یه تصویر پس‌زمینه آپلود کنید.
  5. توی بخش کنترل از راه دور، یه کد اتاق طولانی و مخصوص بنویسید (مثلاً boolooavatar-x7k29qpm41) و اتصال رو بزنید. باید متصل ✓ ببینید.

قدم ۳: استفاده از ریموت (روی گوشی)

  1. آدرس ریموت رو توی مرورگر گوشی باز کنید.
  2. همون کد اتاق رو بنویسید و ذخیره رو بزنید.
  3. دکمه‌ها رو بزنید. دکمه‌های ایموجی ریکشن ایموجی رو اجرا می‌کنن، دکمه‌های 🎬 کلیپ تمام‌اواتار رو پخش می‌کنن و دکمه 🎮 حالت بازی رو روشن و خاموش می‌کنه.
  4. از ویرایش برچسب‌ها می‌تونید اسم دکمه‌های ایموجی و کلیپ رو عوض کنید.

قدم ۴: استفاده توی OBS

  1. صفحه اصلی رو توی کروم باز بذارید و کلید H رو بزنید تا فقط اواتار بمونه (برای برگشت دوباره H یا دابل‌کلیک).
  2. توی OBS یه سورس Window Capture اضافه کنید و پنجره کروم رو انتخاب کنید.
  3. روی سورس راست‌کلیک کنید، Filters رو بزنید و Chroma Key رو اضافه کنید (اگه پس‌زمینه سبزه، رنگ سبز).

راه جایگزین: Browser Source با این آدرس: https://YOURNAME.github.io/boolooavatar/boolooavatar-v3.html?room=YOURCODE#clean. فایل‌های OBS جدا از کروم ذخیره می‌شن، پس فایل‌های اواتار رو دوباره داخل خود OBS آپلود کنید (راست‌کلیک روی سورس ← Interact). برای روشن شدن میکروفون، توی Interact یه بار روی اواتار کلیک کنید.

ریکشن‌ها

  • ریکشن‌های ایموجی (کلیدهای ۱ تا ۵): ایموجی شناور یا یه تصویر کوچیک سفارشی، با صدای اختیاری. توی بخش ریکشن‌های سفارشی ویرایششون کنید.
  • ریکشن‌های کلیپ (کلیدهای Q W E R T): برای هر ریکشن تا ۵ تصویر یا ویدیو که یه لحظه جای اواتار میان و بعد برمی‌گردن. اندازه و پس‌زمینه‌شون رو مثل فایل‌های اواتارتون بگیرید. صدای خود ویدیو بی‌صداست.

کلیدهای میانبر

  • P حالت بازی · H حالت فقط اواتار · 1 تا 5 ریکشن ایموجی · Q W E R T ریکشن کلیپ

روش B: حالت محلی (بدون هیچ محدودیتی)

ویندوز بدون Python: فایل‌های server.ps1 و start-windows.bat رو هم کنار بقیه فایل‌ها توی همون پوشه بذارید و روی start-windows.bat دابل‌کلیک کنید و اجازه ادمین رو بدید. چیزی نیاز به نصب نداره. به‌جای قدم‌های ۲ و ۳ زیر ازش استفاده کنید. اگه ویندوز هشدار آبی SmartScreen نشون داد، More info ← Run anyway رو بزنید.

اگه ریموتی می‌خواید که هیچ محدودیتی از سرویس بیرونی نداشته باشه، سرور کوچیک محلی رو روی کامپیوتر اجرا کنید. گوشی و کامپیوتر باید به یه وای‌فای وصل باشن.

  1. فایل‌های server.py، boolooavatar-v3.html و remote.html رو توی یه پوشه روی کامپیوتر بذارید.
  2. اگه Python ندارید از python.org نصب کنید (توی ویندوز تیک Add Python to PATH رو بزنید).
  3. توی همون پوشه یه ترمینال باز کنید و python server.py رو اجرا کنید. پنجره رو باز نگه دارید. اگه ویندوز درباره فایروال پرسید، اجازه بدید (شبکه خصوصی).
  4. پنجره آدرس‌ها رو چاپ می‌کنه. روی کامپیوتر http://localhost:8765/ رو باز کنید. توی OBS آدرس http://localhost:8765/#clean رو بذارید. روی گوشی http://IP-کامپیوتر:8765/remote رو باز کنید (آدرس دقیق چاپ می‌شه).
  5. توی این حالت کد اتاق لازم نیست و وضعیت «متصل محلی ✓» رو نشون می‌ده. فایل‌های اواتار رو یه بار دوباره آپلود کنید، چون این آدرس حافظه جداگانه داره.

نکته‌ها

  • کد اتاق و ریموت فقط وقتی کار می‌کنن که فایل‌ها رو خودتون هاست کرده باشید (GitHub Pages) یا از روی کامپیوتر باز کنید. روی صفحه‌های هاست‌شده داخل claude.ai کار نمی‌کنن.
  • ریموت از سرورهای رایگان و عمومی MQTT (EMQX و HiveMQ) استفاده می‌کنه. تنها رمز ارتباط، کد اتاقه؛ پس یه کد طولانی بذارید که کسی نتونه حدسش بزنه.
  • فایل‌ها داخل مرورگر همون دستگاه ذخیره می‌شن. مرورگر یا دستگاه دیگه خالی شروع می‌کنه.
  • قابلیت‌های ریموت و OBS توسط سازنده تست نشدن. اگه چیزی کار نکرد، مطمئن بشید کد اتاق توی هر دو جا دقیقاً یکیه.
